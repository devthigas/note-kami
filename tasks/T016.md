## 1. Objetivo Técnico
Desenvolver testes unitários e de requisição para garantir a integridade da persistência de notas, validação de títulos, vinculação com Action Text e resposta Turbo Stream de auto-save.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `test/models/note_test.rb` | **Create** | Testes para o modelo Note e validações |
| `test/controllers/notes_controller_test.rb` | **Create** | Testes de requisição para CRUD e auto-save de notas |

## 3. Passo a Passo de Implementação
1. Em `test/models/note_test.rb`, teste a validação de presença do título (com fallback padrão para 'Sem título').
2. Teste o limite máximo de 200 caracteres no título.
3. Teste a persistência de conteúdo rico em `has_rich_text :content`.
4. Em `test/controllers/notes_controller_test.rb`, teste `POST /notes` criando nova nota e redirecionando para a edição.
5. Teste `PATCH /notes/:id` enviando formato Turbo Stream e verificando resposta HTTP 200 com a substituição do badge de auto-save.
6. Teste `DELETE /notes/:id` assegurando que apenas o proprietário pode excluir a nota.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Testes de modelo cobrem validações e associações de Note.
- [ ] Testes de controller cobrem criação, atualização debounced e exclusão.
- [ ] Asserções Turbo Stream validam o elemento `#auto_save_status`.


### Validação Manual:
Execute os testes e verifique que todas as operações de persistência e validação passam com sucesso.
