## 1. Objetivo Técnico
Construir o mailer transacional para envio de links de acesso com templates HTML e texto puro limpos, responsivos e acessíveis.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/mailers/magic_link_mailer.rb` | **Create** | Mailer com ação sign_in_link |
| `app/views/magic_link_mailer/sign_in_link.html.erb` | **Create** | Template HTML do e-mail com botão de acesso seguro |
| `app/views/magic_link_mailer/sign_in_link.text.erb` | **Create** | Versão texto puro com a URL completa |

## 3. Passo a Passo de Implementação
1. Crie `app/mailers/magic_link_mailer.rb` com o método `def sign_in_link(user, token)`.
2. No mailer, defina `@user = user` e `@url = magic_links_verify_url(token: token)`.
3. Dispare o e-mail com assunto claro: `mail(to: @user.email_address, subject: 'Seu link de acesso ao NoteKami')`.
4. Construa o template HTML com botão destacado e aviso de expiração de 15 minutos.
5. Construa a versão texto com o link completo para clientes de e-mail sem suporte a HTML.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Mailer gera e-mail multipart (HTML e texto plano).
- [ ] Link de acesso contém a rota correta de verificação com o token.
- [ ] Assunto e remetente configurados conforme convenção da aplicação.
