## 1. Objetivo Técnico
Criar teste de sistema com navegador simulado para validar a digitação no editor Lexxy, disparo do evento de debounce e salvamento assíncrono em segundo plano.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `test/system/notes_editing_test.rb` | **Create** | Teste de sistema com interação no editor e auto-save |

## 3. Passo a Passo de Implementação
1. Crie `test/system/notes_editing_test.rb` herdando de `ApplicationSystemTestCase`.
2. Autentique o usuário e navegue para a página de edição de uma nova nota.
3. Preencha o título com 'Minha Anotação com Auto-save'.
4. Digite conteúdo estilizado no elemento do editor Lexxy.
5. Aguarde o temporizador de debounce (750ms a 1s) e assira que o badge '✓ Salvo' é exibido na tela.
6. Recarregue a página com `page.driver.refresh` e confirme que o título e o conteúdo persistem inalterados.

## 4. Critérios de Aceite (Definition of Done)
- [ ] O teste de sistema digita no editor e aguarda a confirmação de auto-save sem recarregar a tela.
- [ ] O badge de status de auto-save atualiza visualmente.
- [ ] O recarregamento da página comprova que os dados foram persistidos no banco SQLite.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails test:system test/system/notes_editing_test.rb
```

### Validação Manual:
Execute o teste e certifique-se de que não ocorrem condições de corrida durante a digitação rápida.
