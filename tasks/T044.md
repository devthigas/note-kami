## 1. Objetivo Técnico
Construir o modal interativo no editor para ligar/desligar o link público de leitura e fornecer um botão de cópia com feedback instantâneo no navegador.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/views/notes/_share_modal.html.erb` | **Create** | Modal de configurações de compartilhamento público |
| `app/javascript/controllers/clipboard_controller.js` | **Create** | Controlador Stimulus para cópia da URL para o clipboard |

## 3. Passo a Passo de Implementação
1. Crie `app/javascript/controllers/clipboard_controller.js` com o método `copy()` usando a API `navigator.clipboard.writeText` e alterando o texto do botão para 'Copiado!'.
2. Em `app/views/notes/_share_modal.html.erb`, inclua o switch interativo para alternar `public_share_enabled` via formulário Turbo.
3. Se o link estiver ativo, renderize o campo com o link público e botão de copiar acoplado ao controlador clipboard.
4. Estilize o modal com Tailwind CSS com animação suave e opção de fechar com tecla Esc ou clique externo.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Modal intuitivo e com feedback imediato de cópia do link.
- [ ] Ativação do link atualiza o estado sem recarregar o editor.
- [ ] URL copiada é válida e funcional.

## 5. Validação e Testes
