## 1. Objetivo Técnico
Construir o controlador Stimulus no frontend para capturar eventos de digitação no título e editor Lexxy, aplicando temporizador de debounce (750ms) para disparar requisições PATCH assíncronas.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/javascript/controllers/auto_save_controller.js` | **Create** | Controlador Stimulus de debouncing e envio de formulário |

## 3. Passo a Passo de Implementação
1. Crie `app/javascript/controllers/auto_save_controller.js` herdando de `Controller` do Stimulus.
2. Declare os alvos (`targets`): `status`, `form`.
3. Declare o valor configurável `delayValue` (padrão: 750).
4. No método `save(event)`: cancele o timeout anterior com `clearTimeout(this.timeout)`.
5. Altere o indicador visual de status para 'Salvando...'.
6. Inicie um novo timeout com `setTimeout`: execute `this.element.requestSubmit()` utilizando o mecanismo nativo do Turbo.
7. No método de sucesso/resposta, atualize o status para '✓ Salvo às HH:MM:SS'.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Digitação repetida não gera rajadas de requisições ao servidor (respeita o debounce de 750ms).
- [ ] Feedback visual ('Salvando...' e '✓ Salvo') é imediato.
- [ ] Submissão é feita via Turbo sem perda de foco no cursor do editor.
