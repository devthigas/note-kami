## 1. Objetivo Técnico
Implementar testes de requisição e modelo para a publicação de links públicos com geração segura de tokens aleatórios, proteção de notas privadas e resposta 404 para links desativados.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `test/controllers/public_notes_controller_test.rb` | **Create** | Testes para o endpoint público /p/:token |
| `test/models/note_test.rb` | **Modify** | Testes para geração de public_share_token e toggle |

## 3. Passo a Passo de Implementação
1. Em `test/models/note_test.rb`, teste a geração de `public_share_token` seguro via `SecureRandom.urlsafe_base64` ao ativar o compartilhamento.
2. Teste se desativar `public_share_enabled = false` impede a visualização da nota.
3. Em `test/controllers/public_notes_controller_test.rb`, teste `GET /p/:token` para uma nota pública ativa retornando HTTP 200 OK sem necessidade de autenticação.
4. Teste `GET /p/:token` para uma nota onde `public_share_enabled: false` retornando HTTP 404 Not Found.
5. Teste `GET /p/:token` com token inexistente retornando HTTP 404.
6. Teste que nenhuma barra de navegação privada ou botões de edição do autor vazam no HTML público renderizado.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Notas públicas são acessíveis sem login.
- [ ] Notas privadas ou desativadas retornam 404 Not Found sem expor informações.
- [ ] Tokens de compartilhamento são criptograficamente seguros e imprevisíveis.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails test test/controllers/public_notes_controller_test.rb
```

### Validação Manual:
Execute os testes e valide a cobertura das respostas 200 e 404.
