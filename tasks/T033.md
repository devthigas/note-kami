## 1. Objetivo Técnico
Criar a tabela de junção `note_collaborators` para registrar permissões de edição/leitura de notas entre múltiplos usuários.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `db/migrate/20261015000005_create_note_collaborators.rb` | **Create** | Migração da tabela note_collaborators com índices e restrições |

## 3. Passo a Passo de Implementação
1. Gere a migração `CreateNoteCollaborators`.
2. Defina os campos:
3.   - `t.references :note, null: false, foreign_key: true, index: true`
4.   - `t.references :user, null: false, foreign_key: true, index: true`
5.   - `t.string :role, null: false, default: 'editor'`
6.   - `t.timestamps`
7. Adicione o índice único composto: `add_index :note_collaborators, [:note_id, :user_id], unique: true`.
8. Execute `bin/rails db:migrate`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Tabela `note_collaborators` criada no banco primário.
- [ ] Índice único composto impede duplicidade de convite para o mesmo usuário na mesma nota.
- [ ] Chaves estrangeiras com integridade referencial configuradas.
