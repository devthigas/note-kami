## 1. Objetivo Técnico
Construir o módulo de autenticação compartilhada para gerenciamento de sessão com cookies seguros, persistência permanente de ID de sessão e exigência de login em rotas protegidas.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/controllers/concerns/authentication.rb` | **Create** | Módulo concern Authentication |
| `app/controllers/application_controller.rb` | **Modify** | Incluir concern Authentication e filtro before_action |

## 3. Passo a Passo de Implementação
1. Crie `app/controllers/concerns/authentication.rb` como concern do ActiveSupport.
2. Implemente `require_authentication`: redireciona para `new_session_path` e salva `session[:return_to_after_authenticating] = request.url` caso não haja usuário ativo.
3. Implemente `resume_session`: localiza a `Session` pelo `cookies.signed.permanent[:session_id]` e atribui `Current.session` e `Current.user`.
4. Implemente `start_new_session_for(user)`: cria sessão e grava cookie assinado.
5. Implemente `terminate_session`: destrói `Current.session` e deleta o cookie.
6. Em `app/controllers/application_controller.rb`, adicione `include Authentication` e `before_action :require_authentication`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Usuário não autenticado tentando acessar telas protegidas é redirecionado para a tela de login.
- [ ] Sessão persistida em cookie assinado mantém login entre requisições.
- [ ] `terminate_session` limpa completamente os rastros de autenticação.
