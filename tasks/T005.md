## 1. Objetivo Técnico
Implementar as classes de modelo ActiveRecord para User e Session, além do CurrentAttributes para armazenamento contextual seguro por requisição.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/models/user.rb` | **Create** | Modelo User com validações e relacionamentos |
| `app/models/session.rb` | **Create** | Modelo Session com belongs_to :user |
| `app/models/current.rb` | **Create** | Classe CurrentAttributes para user e session |

## 3. Passo a Passo de Implementação
1. Crie `app/models/user.rb` herdando de `ApplicationRecord` com `has_secure_password validations: false`.
2. Adicione normalização de email: `normalizes :email_address, with: ->(e) { e.strip.downcase }`.
3. Adicione validações: `validates :name, presence: true, length: { maximum: 100 }` e `validates :email_address, presence: true, uniqueness: { case_sensitive: false }, format: { with: URI::MailTo::EMAIL_REGEXP }` (mantendo `profile_photo` opcional / `allow_nil: true` para armazenamento da URL do avatar vinda do OAuth).
4. Declare associações: `has_many :sessions, dependent: :destroy` e `has_many :oauth_identities, dependent: :destroy`.
5. Crie `app/models/session.rb` herdando de `ApplicationRecord` com `belongs_to :user`.
6. Crie `app/models/current.rb` herdando de `ActiveSupport::CurrentAttributes` e declare `attribute :user, :session`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `User` valida formato e unicidade de email com normalização e suporta o atributo opcional `profile_photo` (`allow_nil: true`).
- [ ] Exclusão de usuário destrói suas sessões associadas.
- [ ] `Current.user` e `Current.session` comportam-se isoladamente entre threads.
