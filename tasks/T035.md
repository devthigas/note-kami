## 1. Objetivo Técnico
Construir o Action Cable Channel (`NoteChannel`) conectado via Solid Cable para transmitir presenças em tempo real, mudanças de título/conteúdo e notificações de revogação de acesso.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/channels/note_channel.rb` | **Create** | Canal Action Cable para stream da nota e presença |

## 3. Passo a Passo de Implementação
1. Crie `app/channels/note_channel.rb` herdando de `ApplicationCable::Channel`.
2. No método `subscribed`: localize a nota por `params[:note_id]`. Verifique se `current_user == @note.user || @note.collaborators.include?(current_user)`. Caso contrário, chame `reject`.
3. Inicie o stream com stream_from("note_#{@note.id}").
4. Implemente a ação `appear`: registre a presença do usuário e transmita broadcast `presence_update` com a lista de usuários ativos (id, nome, cor do avatar, se é owner).
5. Implemente a ação `disappear` (e callback `unsubscribed`): desregistre o usuário e transmita atualização de presença.
6. Implemente método utilitário para broadcast de `content_updated`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Canal restringe subscrições estritamente a usuários autorizados.
- [ ] Broadcasts de presença entregam a lista consolidada de colaboradores na nota.
- [ ] Usa Solid Cable sem qualquer dependência de servidores Redis.
