## 1. Objetivo Técnico
Implementar o controller público de leitura de notas por token sem qualquer exigência de autenticação e com renderização de layout isolado.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/controllers/public_notes_controller.rb` | **Create** | Controller público com ação show por token |
| `config/routes.rb` | **Modify** | Mapear rota get '/p/:token', to: 'public_notes#show', as: :public_note |

## 3. Passo a Passo de Implementação
1. Crie `app/controllers/public_notes_controller.rb` herdando de `ApplicationController`.
2. Adicione `skip_before_action :require_authentication`.
3. Configure layout específico: `layout 'public_note'`.
4. Na ação `show`: busque `@note = Note.find_by!(public_share_token: params[:token], public_share_enabled: true)`.
5. Capture `ActiveRecord::RecordNotFound` e renderize a página `public/404.html` com status 404 Not Found.
6. Em `config/routes.rb`, configure: `get '/p/:token', to: 'public_notes#show', as: :public_note`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Rota acessível publicamente sem login.
- [ ] Retorna 404 se o token não existir ou se o compartilhamento estiver desabilitado.
- [ ] Renderiza usando layout limpo exclusivo para leitura.

## 5. Validação e Testes
### Validação Automatizada:


### Validação Manual:
Acesse uma rota com token inválido (ex: `/p/invalido`) e confirme que a resposta HTTP é 404.
