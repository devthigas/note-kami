## 1. Objetivo Técnico
Construir o componente visual da barra lateral em árvore hierárquica e o controlador Stimulus para expandir/recolher nós de pastas e subpáginas com persistência de estado no localStorage do navegador.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/views/shared/_sidebar_tree.html.erb` | **Create** | Partial de renderização recursiva/aninhada do sidebar |
| `app/javascript/controllers/tree_controller.js` | **Create** | Controlador Stimulus para expansão/recolhimento de nós |

## 3. Passo a Passo de Implementação
1. Crie `app/javascript/controllers/tree_controller.js` com métodos `toggle(event)` para alternar classes de visibilidade (`hidden`) em subitens.
2. Armazene os IDs dos nós abertos em `localStorage` para restaurar o estado ao navegar entre páginas.
3. Crie `app/views/shared/_sidebar_tree.html.erb` renderizando a lista de pastas raízes, suas subpastas e as notas filhas.
4. Adicione ícones de expansão (setas indicativas com transição CSS) e links diretos para cada nota.
5. Integre o partial na barra lateral do layout principal.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Barra lateral renderiza hierarquia com identação clara.
- [ ] Clique no ícone da pasta expande/recolhe o conteúdo sem recarregar.
- [ ] Estado de nós expandidos é mantido ao navegar entre notas.
