## 1. Objetivo Técnico
Desenvolver teste de sistema de ponta a ponta (E2E) simulando a jornada real do usuário no navegador: solicitação de magic link, recebimento de e-mail e autenticação com redirecionamento para o dashboard.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `test/system/authentication_test.rb` | **Create** | Teste de sistema com navegador simulado para login via Magic Link |

## 3. Passo a Passo de Implementação
1. Crie `test/system/authentication_test.rb` herdando de `ApplicationSystemTestCase`.
2. Implemente o fluxo: navegar para `new_magic_link_path`.
3. Preencher o campo de email com um endereço válido e submeter o formulário.
4. Asserir que uma mensagem de sucesso 'Link mágico enviado' é renderizada.
5. Interceptar o e-mail entregue em `ActionMailer::Base.deliveries.last` e extrair a URL de verificação contida no corpo.
6. Visitar a URL extraída e certificar-se de que o usuário se encontra autenticado na URL `/dashboard` com saudação visível.

## 4. Critérios de Aceite (Definition of Done)
- [ ] O teste de sistema executa o fluxo completo do usuário do formulário até o dashboard.
- [ ] A validação do token no link do e-mail é simulada de forma determinística.
- [ ] O teste passa em modo headless.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails test:system test/system/authentication_test.rb
```

### Validação Manual:
Execute o teste em modo não-headless se desejar inspecionar visualmente os passos no navegador.
