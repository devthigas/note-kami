## 1. Objetivo Técnico
Adicionar o endpoint e ação `sub_pages` no `NotesController` para criação ágil de uma subpágina aninhada a partir de uma nota ativa aberta no editor.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/controllers/notes_controller.rb` | **Modify** | Adicionar ação create_sub_page ou sub_pages |
| `config/routes.rb` | **Modify** | Mapear rota nested: post :sub_pages no resources :notes |

## 3. Passo a Passo de Implementação
1. Em `config/routes.rb`, configure o recurso aninhado:
2.   `resources :notes do; member { post :sub_pages }; end` (ou `resources :sub_pages, only: [:create]`).
3. Em `app/controllers/notes_controller.rb`, implemente o método para criar uma nova nota com `parent_note_id: @parent_note.id` e mesmo `folder_id` se aplicável.
4. Ao criar com sucesso, redirecione para o editor da nova subpágina ou anexe o nó filho na árvore lateral via Turbo Stream.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Subpágina herda o relacionamento com o pai e o proprietário.
- [ ] Redirecionamento imediato para a tela de edição da subpágina recém-criada.
- [ ] Atualização fluida da árvore de navegação.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails test test/controllers/notes_controller_test.rb
```

### Validação Manual:
Dentro do editor de uma nota, clique em 'Adicionar Subpágina' e confira a transição de tela para o novo documento.
