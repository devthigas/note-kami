## 1. Objetivo Técnico
Implementar o controller de notas gerenciando ações RESTful (new, create, edit, update, destroy) com suporte a respostas Turbo Stream para atualização debounced sem reload.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/controllers/notes_controller.rb` | **Create** | Controller RESTful para criação, edição e auto-save de notas |
| `config/routes.rb` | **Modify** | Declarar rotas resources :notes |

## 3. Passo a Passo de Implementação
1. Em `app/controllers/notes_controller.rb`, adicione filtro para carregar `@note = Current.user.notes.find(params[:id])` (ou notas com colaboração).
2. Na ação `create`: crie nota vinculada a `Current.user` e redirecione para `edit_note_path(@note)`.
3. Na ação `update`: atualize parâmetros com `note_params` (`title`, `content`, `folder_id`).
4. Ao salvar com sucesso, responda com `format.turbo_stream` (renderizando partial de status de auto-save) ou `format.html`.
5. Na ação `destroy`: remova a nota e responda redirecionando para o dashboard ou removendo o elemento da árvore com Turbo Stream.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Usuário só pode editar e remover suas próprias notas (ou autorizadas).
- [ ] Ação `update` aceita requisições assíncronas de auto-save via Turbo Stream.
- [ ] Retorna HTTP 200 e substitui `#auto_save_status` na tela.
