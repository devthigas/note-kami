## 1. Objetivo Técnico
Implementar testes de unidade e integração para validar o aninhamento hierárquico de pastas, integridade da chave estrangeira pai/filho e rejeição absoluta de ciclos circulares (uma pasta não pode ser pai de si mesma nem de seus descendentes).

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `test/models/folder_test.rb` | **Create** | Testes para hierarquia de pastas e cycle prevention |
| `test/controllers/folders_controller_test.rb` | **Create** | Testes para criação, renomeação e exclusão segura de pastas |

## 3. Passo a Passo de Implementação
1. Em `test/models/folder_test.rb`, teste a criação de pasta raiz sem pasta pai (`parent_folder_id: nil`).
2. Teste a criação de subpastas associadas (`folder.sub_folders.create!(name: 'Sub')`).
3. Teste a validação contra aninhamento circular: `folder.parent_folder = folder; assert_not folder.valid?`.
4. Teste ciclo indireto: se A -> B -> C, tentar definir A.parent_folder = C deve ser inválido.
5. Em `test/controllers/folders_controller_test.rb`, teste `POST /folders` criando pasta com sucesso e retornando Turbo Stream.
6. Teste `DELETE /folders/:id` verificando que a pasta é removida e as notas contidas têm `folder_id` definido como nil (`dependent: :nullify`).

## 4. Critérios de Aceite (Definition of Done)
- [ ] Testes de validação de ciclo cobrem auto-referência direta e ciclos em cadeia.
- [ ] Testes de controller garantem respostas Turbo Stream para atualização do sidebar.
- [ ] Exclusão de pasta não apaga as notas filhas do usuário.

## 5. Validação e Testes
### Validação Automatizada:


### Validação Manual:
Execute os testes de ciclo e confirme que erros de ciclo adicionam mensagens de validação descritivas.
