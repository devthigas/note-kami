## 1. Objetivo Técnico
Instalar tabelas do Action Text (para armazenamento de rich text via Lexxy) e criar a tabela `notes` com campos de título, chaves estrangeiras de pasta/pai e atributos de compartilhamento.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `db/migrate/20261015000002_create_notes.rb` | **Create** | Migração da tabela notes com índices |
| `db/migrate/20261015000003_create_action_text_tables.rb` | **Create** | Migração nativa do Action Text |

## 3. Passo a Passo de Implementação
1. Execute `bin/rails action_text:install` se as migrações do Action Text ainda não estiverem presentes.
2. Crie a migração `CreateNotes`.
3. Na tabela `notes`, adicione:
4.   - `t.references :user, null: false, foreign_key: true, index: true`
5.   - `t.references :folder, null: true, foreign_key: true, index: true`
6.   - `t.references :parent_note, null: true, foreign_key: { to_table: :notes }, index: true`
7.   - `t.string :title, null: false, default: 'Sem título'`
8.   - `t.boolean :public_share_enabled, null: false, default: false, index: true`
9.   - `t.string :public_share_token, null: true, index: { unique: true }`
10.   - `t.timestamps`
11. Execute `bin/rails db:migrate`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Tabela `notes` provisionada com índices para chaves estrangeiras e tokens.
- [ ] Tabelas do Action Text (`action_text_rich_texts`) instaladas.
- [ ] Execução da migração concluída sem erros no banco primário.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails db:migrate
bin/rails runner 'puts ActiveRecord::Base.connection.tables.grep(/notes|action_text/)'
```

### Validação Manual:
Inspecione `db/schema.rb` para conferir a integridade das colunas da tabela `notes`.
