## 1. Objetivo Técnico
Auditar e padronizar todo o código-fonte Ruby da aplicação com base no guia oficial de estilo Omakase (`rubocop-rails-omakase`), garantindo simplicidade e elegância.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `.rubocop.yml` | **Modify** | Ajustar regras ou herança do rubocop-rails-omakase |
| `app/` | **Modify** | Padronizar formatações de controllers, models e helpers |
| `test/` | **Modify** | Padronizar formatações de testes |

## 3. Passo a Passo de Implementação
1. Verifique se `.rubocop.yml` herda de `rubocop-rails-omakase` conforme o Princípio III da Constituição.
2. Execute `bundle exec rubocop` para identificar todas as violações de convenção e estilo.
3. Execute `bundle exec rubocop -a` (ou `-A` quando seguro) para autocorreção dos aspectos formais.
4. Revise manualmente os pontos restantes e certifique-se de que nenhum método excede responsabilidade única ou utiliza construções enigmáticas.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `bundle exec rubocop` executa e retorna 0 ofensas pendentes.
- [ ] Código segue rigorosamente os princípios de elegância e convenção sobre configuração.
- [ ] Nenhuma regra arquitetural da constituição foi contornada.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bundle exec rubocop
```

### Validação Manual:
Inspecione os diffs gerados pelo RuboCop e confirme a legibilidade do código.
