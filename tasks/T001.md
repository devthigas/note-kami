## 1. Objetivo Técnico
Integrar a gem Lexxy para suporte ao editor de texto rico baseado em árvore sintática abstrata (AST) compatível com Action Text e adicionar a gem Hotwire Spark no grupo de desenvolvimento para morphing instantâneo e live reload sem bundlers Node.js.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `Gemfile` | **Modify** | Declarar as gems 'lexxy' e 'hotwire-spark' (no grupo :development) |
| `Gemfile.lock` | **Modify** | Resolver e travar as versões exatas das novas gems instaladas |

## 3. Passo a Passo de Implementação
1. Abra o arquivo `Gemfile` na raiz do projeto.
2. Adicione `gem "lexxy"` no escopo principal de dependências.
3. Dentro do bloco `group :development do`, adicione a linha: `gem "hotwire-spark"`.
4. Abra o terminal e execute: `bundle install`.
5. Certifique-se de que o comando finaliza com sucesso e gera as entradas correspondentes no `Gemfile.lock`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `Gemfile` contém `gem "lexxy"`.
- [ ] `Gemfile` contém `gem "hotwire-spark"` sob o bloco `:development`.
- [ ] `bundle install` retorna código de saída 0.
- [ ] Nenhum arquivo Node.js/package.json é gerado ou exigido.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bundle exec gem list | grep -E "lexxy|hotwire-spark"
bin/rails runner 'puts Lexxy rescue nil'
```

### Validação Manual:
Inicie o servidor de desenvolvimento e confirme que a aplicação sobe sem advertências de dependências ausentes.
