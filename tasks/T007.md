## 1. Objetivo Técnico
Configurar o Action Mailer para entregas locais de e-mails transacionais e implementar o layout mestre da aplicação com tipografia, componentes de alerta e cabeçalho do usuário.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `config/environments/development.rb` | **Modify** | Definir host do mailer e método de entrega em desenvolvimento |
| `app/views/layouts/application.html.erb` | **Modify** | Layout HTML5 com Tailwind, Hotwire e flash notifications |

## 3. Passo a Passo de Implementação
1. Em `config/environments/development.rb`, defina `config.action_mailer.default_url_options = { host: 'localhost', port: 3000 }`.
2. Configure `config.action_mailer.delivery_method = :test` (ou `:letter_opener`).
3. Edite `app/views/layouts/application.html.erb` estruturando o grid principal:
4.   - Adicione tags de viewport, stylesheet e importmaps.
5.   - Adicione bloco condicional para renderização de flash notices e alerts com classes Tailwind de alto contraste.
6.   - Adicione a barra de navegação superior exibindo o nome de `Current.user` e formulário de `button_to 'Sair', session_path, method: :delete`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Action Mailer devidamente configurado para gerar links com host e porta corretos.
- [ ] Layout responsivo e acessível estilizado com Tailwind CSS.
- [ ] Mensagens de flash são visíveis e limpas automaticamente ou ao navegar com Turbo.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails runner 'puts Rails.application.config.action_mailer.default_url_options[:host]'
```

### Validação Manual:
Abra a aplicação no navegador e valide a renderização da tipografia Tailwind e cabeçalho sem erros no console.
