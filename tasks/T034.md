## 1. Objetivo Técnico
Implementar a classe de modelo `NoteCollaborator` com associações, validação de unicidade de escopo, lista permitida de papéis e regra de domínio que impede o proprietário de se auto-adicionar.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/models/note_collaborator.rb` | **Create** | Modelo NoteCollaborator com regras de domínio |
| `app/models/note.rb` | **Modify** | Adicionar has_many :note_collaborators e has_many :collaborators |
| `app/models/user.rb` | **Modify** | Adicionar has_many :collaborative_notes |

## 3. Passo a Passo de Implementação
1. Crie `app/models/note_collaborator.rb` herdando de `ApplicationRecord`.
2. Declare `belongs_to :note` e `belongs_to :user`.
3. Adicione validações:
4.   - `validates :user_id, uniqueness: { scope: :note_id, message: 'já é um colaborador desta nota' }`
5.   - `validates :role, inclusion: { in: %w[editor viewer] }`
6. Implemente a validação customizada:
7.   `validate :owner_cannot_be_collaborator` -> se `note.user_id == user_id`, adicione erro.
8. Em `app/models/note.rb`, declare `has_many :note_collaborators, dependent: :destroy` e `has_many :collaborators, through: :note_collaborators, source: :user`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Impede adição redundante do mesmo colaborador.
- [ ] Impede que o autor da nota seja cadastrado como colaborador de si mesmo.
- [ ] Papel é validado como editor ou viewer.
