## 1. Objetivo Técnico
Implementar a classe de domínio `Note` com integração ao Action Text, validação de limites de título, scopes de ordenação e métodos utilitários de estado.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/models/note.rb` | **Create** | Modelo Note com has_rich_text e validações |

## 3. Passo a Passo de Implementação
1. Crie `app/models/note.rb` herdando de `ApplicationRecord`.
2. Adicione `has_rich_text :content`.
3. Configure as associações: `belongs_to :user`, `belongs_to :folder, optional: true`.
4. Adicione validações: `validates :title, presence: true, length: { maximum: 200 }`.
5. Defina callbacks: se `title.blank?`, atribua o valor `'Sem título'`.
6. Defina scopes: `scope :recent, -> { order(updated_at: :desc) }`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `Note` armazena e recupera conteúdo formatado através de Action Text.
- [ ] Título não pode exceder 200 caracteres.
- [ ] Nota pertence obrigatoriamente a um `User`.
