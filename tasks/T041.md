## 1. Objetivo Técnico
Adicionar a ação de alternância de compartilhamento público (`public_share`) no controller de notas para gerar ou invalidar o token e responder via JSON e Turbo Stream.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/controllers/notes_controller.rb` | **Modify** | Adicionar ação public_share |
| `config/routes.rb` | **Modify** | Declarar patch :public_share no recurso notes |

## 3. Passo a Passo de Implementação
1. Em `config/routes.rb`, declare `patch :public_share, on: :member` dentro do bloco `resources :notes`.
2. Em `app/controllers/notes_controller.rb`, implemente `def public_share`:
3.   - `@note = Current.user.notes.find(params[:id])`
4.   - Se `params[:public_share_enabled]` for true e `@note.public_share_token.blank?`, gere um token com `SecureRandom.urlsafe_base64(24)`.
5.   - Atualize os atributos da nota (`public_share_enabled`).
6.   - Responda com JSON contendo `public_share_enabled` e a `public_url` (`public_note_url(token: @note.public_share_token)`), ou via Turbo Stream atualizando o modal.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Apenas o dono da nota pode alterar o estado do link público.
- [ ] Token único gerado na primeira ativação e mantido para reativações convenientes.
- [ ] Resposta fornece a URL pública pronta para cópia pelo usuário.
