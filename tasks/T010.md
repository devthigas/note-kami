## 1. Objetivo Técnico
Utilizar o gerador nativo de tokens do Rails 8 (`generates_token_for`) no modelo User para produzir links mágicos seguros com tempo de expiração de 15 minutos e invalidação automática em logins subsequentes.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/models/user.rb` | **Modify** | Configurar generates_token_for :magic_link com bloco de dados de invalidação |

## 3. Passo a Passo de Implementação
1. Abra `app/models/user.rb`.
2. Declare: `generates_token_for :magic_link, expires_in: 15.minutes { last_sign_in_at }`.
3. Opcionalmente, crie método auxiliar `touch_last_sign_in!` para atualizar `last_sign_in_at: Time.current` após login com sucesso.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `user.generate_token_for(:magic_link)` produz token assinado.
- [ ] Tokens expiram automaticamente após 15 minutos.
- [ ] Alterar `last_sign_in_at` invalida imediatamente qualquer token anterior do usuário.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails runner 'u = User.first; t = u.generate_token_for(:magic_link); puts User.find_by_token_for(:magic_link, t) == u'
```

### Validação Manual:
Teste a geração no console e certifique-se de que o token é compacto e seguro para URLs.
