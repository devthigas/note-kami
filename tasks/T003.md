## 1. Objetivo Técnico
Configurar o gerenciamento de assets JavaScript do editor Lexxy e Stimulus via Importmaps sem a necessidade de Node.js, Webpack ou Vite.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `config/importmap.rb` | **Modify** | Adicionar pin para lexxy e @rails/activestorage |
| `app/javascript/application.js` | **Modify** | Importar o módulo lexxy na inicialização da aplicação |

## 3. Passo a Passo de Implementação
1. Edite `config/importmap.rb` e adicione os pins necessários: `pin "lexxy"` e verifique `@rails/activestorage`.
2. No arquivo `app/javascript/application.js`, adicione `import "lexxy";`.
3. Verifique se `@hotwired/stimulus` e `@hotwired/turbo-rails` já se encontram importados e mapeados.
4. Execute `bin/rails importmap:verify` para validar os scripts mapeados.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `config/importmap.rb` contém pin de `lexxy`.
- [ ] `app/javascript/application.js` importa o módulo do editor Lexxy.
- [ ] `bin/rails importmap:verify` retorna sucesso.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails importmap:verify
grep 'lexxy' config/importmap.rb
```

### Validação Manual:
Abra o navegador, inspecione a aba Network e confirme que `lexxy.js` é carregado sem erros de import.
