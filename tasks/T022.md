## 1. Objetivo Técnico
Construir a interface do editor de notas com campo de título integrado, canvas do Lexxy, barra de status de salvamento automático e menu de opções da nota estilizado com Tailwind CSS.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/views/notes/edit.html.erb` | **Create** | Página completa de edição da nota |
| `app/views/notes/_form.html.erb` | **Create** | Formulário encapsulado com auto_save stimulus controller |
| `app/views/notes/_auto_save_status.html.erb` | **Create** | Partial com badge de status de salvamento |

## 3. Passo a Passo de Implementação
1. Crie `app/views/notes/_auto_save_status.html.erb` com o elemento `<span id="auto_save_status">`.
2. Em `app/views/notes/_form.html.erb`, envolva o formulário com o controller Stimulus: `data-controller="auto-save"`.
3. Adicione o input de título com fonte grande, sem borda externa, com listener `data-action="input->auto-save#save"`.
4. Adicione o campo de rich text do Lexxy: `<%= form.rich_textarea :content, data: { action: "lexxy:change->auto-save#save" } %>`.
5. Em `app/views/notes/edit.html.erb`, estruture o header da página exibindo a navegação de breadcrumbs (Pasta > Nota), o badge `#auto_save_status` e botões de compartilhamento.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Editor limpo, sem distrações e com foco natural de escrita.
- [ ] Integração perfeita entre o componente Lexxy e o formulário do Rails.
- [ ] Badge `#auto_save_status` presente e responsivo às ações de persistência.
