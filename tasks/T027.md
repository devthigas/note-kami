## 1. Objetivo Técnico
Evoluir o modelo `Note` para permitir que notas contenham subpáginas aninhadas (`parent_note_id`), incorporando validação de prevenção de ciclos idêntica à de pastas.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `app/models/note.rb` | **Modify** | Adicionar auto-associação parent_note / sub_pages e validação de ciclo |

## 3. Passo a Passo de Implementação
1. Abra `app/models/note.rb`.
2. Adicione as associações de árvore de notas:
3.   - `belongs_to :parent_note, class_name: 'Note', optional: true`
4.   - `has_many :sub_pages, class_name: 'Note', foreign_key: :parent_note_id, dependent: :destroy`
5. Adicione o validador customizado: `validate :prevent_circular_nesting`.
6. Implemente a lógica de travessia de ancestrais para impedir que uma nota tenha como pai uma de suas subpáginas diretas ou descendentes.

## 4. Critérios de Aceite (Definition of Done)
- [ ] `Note` aceita subpáginas filhas que são deletadas se a nota pai for excluída.
- [ ] Tentativa de criar loop circular entre notas é barrada com erro de validação.
- [ ] Testes unitários de árvore de subpáginas passam com 100% de sucesso.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails test test/models/note_test.rb
```

### Validação Manual:
No console, crie uma nota A, crie uma subpágina B e certifique-se de que `A.sub_pages` contém B.
