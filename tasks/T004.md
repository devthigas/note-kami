## 1. Objetivo Técnico
Criar a migração do banco de dados para os modelos fundamentais de autenticação nativa do Rails 8, controle de sessões e integração com identidades Google OAuth.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `db/migrate/20261015000001_create_users_sessions_oauth.rb` | **Create** | Migração de criação das tabelas users, sessions e oauth_identities |

## 3. Passo a Passo de Implementação
1. Crie uma nova migração com o comando `bin/rails g migration CreateUsersSessionsOauth`.
2. Estruture a tabela `users`: `t.string :name, null: false`, `t.string :profile_photo, null: true` (armazena a URL da foto de perfil vinda do provedor OAuth; upload manual será implementado em especificações futuras), `t.string :email_address, null: false, index: { unique: true }`, `t.string :password_digest, null: true` e `t.datetime :last_sign_in_at`.
3. Estruture a tabela `sessions`: `t.references :user, null: false, foreign_key: true, index: true`, `t.string :ip_address` e `t.string :user_agent`.
4. Estruture a tabela `oauth_identities`: `t.references :user, null: false, foreign_key: true, index: true`, `t.string :provider, null: false`, `t.string :uid, null: false`, `t.string :email`, com índice único em `[:provider, :uid]`.
5. Execute `bin/rails db:migrate`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Tabela `users` criada com restrição de unicidade em `email_address` e coluna opcional `profile_photo` (`string`, `null: true`).
- [ ] Tabela `sessions` com chave estrangeira e índice para `users`.
- [ ] Tabela `oauth_identities` com índice único composto em `[:provider, :uid]`.
- [ ] Migração roda de ponta a ponta sem erros e atualiza `db/schema.rb`.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails db:migrate
bin/rails runner 'puts ActiveRecord::Base.connection.tables.grep(/users|sessions|oauth/)'
```

### Validação Manual:
Inspecione `db/schema.rb` e confira a integridade das colunas e chaves estrangeiras geradas.
