## 1. Objetivo Técnico
Criar a tabela `folders` para agrupamento hierárquico e assegurar a existência dos campos `folder_id` e `parent_note_id` na tabela `notes` com as devidas chaves estrangeiras e índices de busca.

## 2. Arquivos Impactados
| Arquivo | Ação | Descrição |
| :--- | :--- | :--- |
| `db/migrate/20261015000004_create_folders.rb` | **Create** | Criação da tabela folders com auto-relacionamento |

## 3. Passo a Passo de Implementação
1. Crie a migração `CreateFolders` com `bin/rails g migration CreateFolders`.
2. Estruture a tabela `folders`:
3.   - `t.references :user, null: false, foreign_key: true, index: true`
4.   - `t.references :parent_folder, null: true, foreign_key: { to_table: :folders }, index: true`
5.   - `t.string :name, null: false`
6.   - `t.timestamps`
7. Se necessário, certifique-se de que a tabela `notes` possui chave estrangeira para `folders` e auto-relacionamento em `parent_note_id`.
8. Execute `bin/rails db:migrate`.

## 4. Critérios de Aceite (Definition of Done)
- [ ] Tabela `folders` criada com chave estrangeira opcional para si mesma (`parent_folder_id`).
- [ ] Chave estrangeira `user_id` vincula pastas ao respectivo proprietário.
- [ ] Migração roda com sucesso e atualiza `db/schema.rb`.

## 5. Validação e Testes
### Validação Automatizada:
```bash
bin/rails db:migrate
bin/rails runner 'puts ActiveRecord::Base.connection.tables.grep(/folders/)'
```

### Validação Manual:
Inspecione `db/schema.rb` e confira a integridade das referências circulares opcionais.
